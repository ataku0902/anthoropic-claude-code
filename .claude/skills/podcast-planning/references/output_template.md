# 企画書の出力テンプレート

Obsidianのvaultに置く前提のMarkdown。以下の構造をそのまま使う。
`{{ }}` は埋める箇所。埋められない項目は空欄で残さず、ユーザーに聞いてから埋める。

フロントマターの `tags` と、20本リストのチェックボックス `- [ ]` は必ず残す。
Obsidian側でタグ検索と配信進捗の管理に使うため、ここを普通の箇条書きに変えると機能が落ちる。

---

## 埋めるときの注意

**「9. 次にやること」は削らない。** 企画書は作った時点では何も生んでおらず、身体感覚のフィードバック（人に話して反応を見る）を経て初めて精度が上がる。ここを落とすと、企画書が机上で完結してしまう。

**20本が埋まらないまま出力しない。** 空欄のまま渡すと「あとで埋めればいい」と処理され、コンセプトが検証されないまま配信が始まる。埋まらない場合は出力を止め、Phase 1 に戻る判断をユーザーに伝える。
